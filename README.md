# Portfolio website starter

A static HTML/CSS portfolio for GitHub Pages, with a Portals case study.

## Start

1. Extract this ZIP into the **root** of your `YOUR-USERNAME.github.io` repository (not inside an extra nested folder).
2. Open the folder in VS Code. Open `index.html` with a local preview extension or browser.
3. Replace `YOUR NAME` in the HTML files and customize `about.html` and `contact.html` before publishing.
4. Review `projects/portals.html` and replace placeholder artwork as your updated assets become available.
5. Commit and push the files to the `main` branch.
6. On GitHub, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
7. The site should appear at `https://YOUR-USERNAME.github.io/` after deployment completes.

## Files
- `index.html`: portfolio home / project list
- `projects/portals.html`: Portals case study
- `about.html`, `contact.html`: starter pages
- `css/style.css`: global design, navigation, hero, responsive layout
- `assets/portals/`: transparent logo artwork

## Important
- The six class logos are temporary recolorings of older artwork in palette order: Warrior (red), Savant (yellow), Caster (green), Mage (blue), Technician (purple), Artisan (pink). Replace them with your final files.
- The Portals wordmark is based on your provided artwork.
- The decorative hero is implemented in CSS, not a flattened image.
- The About and Contact pages are placeholders; update before sharing with employers.
- No build system, framework, or dependencies are required.
